## English

# Data

`WA_Fn-UseC_-Telco-Customer-Churn.csv` is the public **Telco Customer Churn** dataset: 7,043 customers, 21 columns. It is included in this folder, so no download is needed to run the notebook.

Original source: [Telco Customer Churn on Kaggle](https://www.kaggle.com/datasets/blastchar/telco-customer-churn).

### Columns

- **Customer:** `customerID`, `gender`, `SeniorCitizen`, `Partner`, `Dependents`, `tenure` (months as a customer).
- **Services:** `PhoneService`, `MultipleLines`, `InternetService`, `OnlineSecurity`, `OnlineBackup`, `DeviceProtection`, `TechSupport`, `StreamingTV`, `StreamingMovies`.
- **Contract and billing:** `Contract`, `PaperlessBilling`, `PaymentMethod`, `MonthlyCharges`, `TotalCharges`.
- **Target variable:** `Churn` (`Yes` if the customer left, `No` if they stayed).
